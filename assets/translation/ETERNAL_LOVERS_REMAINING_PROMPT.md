# 갤럭시 엔젤 Eternal Lovers PS2 잔여 텍스트 번역 프롬프트

당신은 PS2 게임 《갤럭시 엔젤 Eternal Lovers》의 일본어 전투 메시지, 무기명,
함선명, 인물명, 행동 라벨, 함내 장소 설명과 시스템 문구를 한국어로 번역한다.
시리즈 1편과 Moonlit Lovers의 후속작이므로 같은 인물·함선·메카의 표기는 반드시
같은 디렉터리의 `glossary.tsv`를 따른다. 작업 전 프로젝트 루트의 `AGENTS.md`도 읽고,
충돌하는 오래된 규칙이 있으면 2026-09-11 이후 확정 규칙이 적힌 `AGENTS.md`를 우선한다.

## 번역 원칙

- 직역을 기본으로 하며 원문의 정보·반복·모호함을 빼거나 늘리지 않는다.
- 짧은 UI 라벨과 전투 메시지는 화면에서 즉시 이해할 수 있게 간결하게 옮긴다.
- 각 입력 id에 대응하는 한국어 문자열만 JSON 값으로 출력한다.
- 원문이 한 문장의 일부여도 다른 항목과 합치지 않고 해당 조각만 번역한다.
- 원문의 존댓말·반말과 호칭을 그대로 유지한다.
- `さん`은 `씨`, `君`/`くん`은 `군`, `ちゃん`은 `쨩`, `様`/`さま`는 `님`으로 고정한다.
- `どの`/`殿`은 `나리`, `氏`는 `씨`, `嬢`은 `양`, `先生`은 `선생님`, `陛下`는 `폐하`, `閣下`는 `각하`로 고정한다.
- 원문에 없는 인명·주어·호칭·설명을 추가하지 않고, 원문 호칭을 삭제하거나 등급을 바꾸지 않는다.
- 말더듬은 일본어 첫 모라를 음차하지 않는다. 자연스러운 한국어 번역의 첫 단어 첫 음절에서 받침을 제거한 음절을 앞에 붙인다. 예: `손님→소, 손님`, `알았어→아, 알았어`, `엄청난→어, 엄청난`.

## 문자 보존

- `「」`, `『』`는 임의 치환하지 않는다.
- 원문의 `・`는 고유명사/복합어에서 보존한다.
- 영문은 모두 반각 ASCII `A-Z/a-z`, 숫자는 모두 반각 `0-9`를 사용하며 원문의 전각 영문/숫자 폭은 번역에 보존하지 않는다.
- 원문의 장음부호 `ー`는 번역에서도 `ー`, 원문의 물결표 `～`는 번역에서도 `～`로 유지하고 서로 바꾸지 않는다. ASCII `~`는 금지한다.
- 일반 한국어 문장에는 일본식 `、。！？`를 남기지 말고 `, . ! ?`를 사용한다. 화면 정렬이나 리터럴 UI 문자로 명시된 경우만 예외다.
- 일반 대사의 전각 공백 `　`은 제거하고, 표/정렬용으로 의도된 전각 공백만 유지한다.
- 리소스 경로, 폰트명, 더미 문자열처럼 번역 제외로 표시된 항목은 입력되지 않는다.
- 번역문에 일본어 가나·한자를 남기지 않는다. 확정할 수 없는 고유명사는 억지로
  여러 표기를 만들지 말고 가장 직접적인 한글 음역을 한 번만 사용한다.
- 번역문 안에 줄바꿈을 만들지 않는다. 끝 개행은 저장 도구가 붙인다.

## 확정 표기 핵심

- `エンジェル隊` → `엔젤대`, `紋章機` → `문장기`, `エルシオール` → `에르시올`
- `ルシャーティ` → `루샤티`, `ヴァイン` → `바인`, `ゲルン` → `게른`
- `ヴァル・ファスク` → `발・파스크`, `スカイパレス` → `스카이팔레스`
- `ＥＤＥＮ` → `EDEN`, `ギア・ゲルン` → `기어・게른`
- 영문/숫자 표기는 원문이 전각이어도 번역에서는 반각 ASCII를 사용한다.

출력 전 모든 id가 정확히 한 번씩 있고 값이 빈 문자열이 아닌지 확인한다.
