## v0.4.11 번역 누락·전투 UI 후속 수정 및 저장 제목 안정화

- 짧은 암호화 구간의 키 감지 오류를 고쳐, 대사·이름·저장 제목 등 누락된 표시 레코드 14개를 복구했습니다. 예: `よしっ、やるぞっ！` → `좋아, 가자!`. 동일 원인의 다른 구간도 함께 처리했습니다.
- 기술명 `앙카 클로` 계열을 `앵커 클로`로 통일하고, 긴 문장 축약 중 사라진 띄어쓰기를 보완했습니다. 전투 대사는 34칸/최대 3줄 기준으로 점검했습니다.
- 기체명은 **쿵후 파이터**로 통일했습니다. 대사·용어집·기체명/목표 안내/결과표 이미지와 해당 영상 자막을 함께 반영했습니다.
- 전투 UI 복사본의 축소 재그리기와 추가 팔레트 축약 경로를 제거했습니다. 현재 수동 편집 PNG를 보존하고, 관련 없는 리소스의 주소/크기/압축 바이트가 변하지 않도록 검사합니다. 전투 UI 복사본 1,382개 픽셀 대조를 통과했습니다.
- 불필요한 빈 ASS와 대응 자막용 PSS를 제거했습니다. 실제 자막 영상 24개는 현재 권위 PSS와, 제외 영상 15개는 일본판 원본과 해시가 일치합니다.
- 기존 문자표에서 이동했던 730개 한글 코드를 복구하고 1,245개 코드 배치를 고정했습니다. 저장 제목의 반각 공백 판별 오류 및 2바이트 문자 중간 잘림도 수정했습니다.

### 세이브 호환성

기존 세이브/세이브스테이트에 저장된 제목은 이전 문자 코드를 그대로 이어받을 수 있으며, 재저장해도 남을 수 있습니다. 예를 들어 이전 코드의 `프롤로그`가 현재 문자표에서 `퓩롤로그`로 표시될 수 있습니다. 최신 ISO의 원문/번역/인코딩 결과는 정상이며, 새 게임에서 정상 표시되는 것을 사용자도 확인했습니다. 기존 저장 데이터의 제목을 자동 변환하는 기능은 포함하지 않았습니다.

기존 일반 세이브 불러오기 → 새 슬롯 일반 저장 → 재불러오기를 확인했습니다. 이는 검사한 위치에 한정하며, 모든 저장 경로를 보증하지 않습니다. 원본 메모리카드는 변경하지 않았습니다.

### 프리징 및 잔여 사항

프리징은 관련 원인 수정 후 개선된 것으로 보이지만, 완전히 해결됐다고 확정할 수는 없습니다. 제보자께 추가 플레이 검증을 요청하지 않고, 향후 동일 증상이 다시 제보되면 당시 세이브와 실행 환경을 기준으로 재확인하겠습니다.

BGM 백색 소음 및 작전정보 화면의 음 깨짐은 해결 확인이 끝나지 않은 별도 항목입니다. 저장 제목 수정만으로 오디오 문제까지 해결됐다고 판단하지 않습니다.

### 검증과 상세 내역

일본판 원본에 배포 xdelta를 다시 적용하여 검증 ISO의 SHA-256과 일치하는지 확인한 뒤 배포합니다. ISO 자체는 배포하지 않습니다. 원본과 결과 ISO 및 패치 해시는 첨부한 `README.txt`, `SHA256SUMS.txt`에 있습니다.

항목별 변경 전후와 유지 사유는 [후속 검수 기록](https://github.com/TAMTAMQ/galaxy-angel-eternal-lovers-korean-translation-patch/blob/v0.4.11/ISSUE_1_FOLLOWUP_20261018.md), [저장 제목 수정 기록](https://github.com/TAMTAMQ/galaxy-angel-eternal-lovers-korean-translation-patch/blob/v0.4.11/SAVE_TITLE_FIX_20261019.md)을 참고해 주세요. 이 릴리즈 안내가 앞선 기록의 '로컬 ISO만 생성' 상태를 대체합니다.
